┌────────────────────────────────────────────────────────────────────────────┐
│ 🛠️ TROUBLESHOOTING                                                          │
└────────────────────────────────────────────────────────────────────────────┘

  Problem: Command not found
    Fix: chmod +x setup.sh start.sh

  Problem: Node.js not found
    Fix: Install from https://nodejs.org/ (18+)

  Problem: Port 3000 in use
    Mac/Linux: lsof -ti:3000 | xargs kill -9
    Windows:   taskkill /F /PID [PID]

  Problem: Server won't start
    Fix: ./setup.sh (run setup again)

  Problem: Need to check data
    Fix: node scripts/validate-data.js
